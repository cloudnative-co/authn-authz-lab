# 認証認可入門 読解評価

完全コースの各回、またはコードを実行しない読解のみの経路で使う開始点です。第01回から順に記事を読み、各回5問へ回答します。4問以上でその回の読解評価は合格です。完全コースでは記事内の同じ番号の実習とrequired checkを一度だけ終え、記事を読み終えた後にここへ来ます。合格後は実習を繰り返さず、次の記事へ進みます。

不正解は各問題に書かれた記事見出しへ戻って読み直します。解答は同じLessonの`answer-key.md`にあります。これは理解を確かめる形成的評価（formative assessment）であり、実習checkやAA-CO3の実行技能を置き換えません。
